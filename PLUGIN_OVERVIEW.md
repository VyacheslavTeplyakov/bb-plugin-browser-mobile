Switch between phone, tablet and desktop layout widths while browsing a site inside BB. A compact toolbar control shows the current width, and a themed menu opens over the live website inside its viewport.

## What you get

- Fixed widths of 360, 390, 430, 768, 1024 and 1280 CSS pixels.
- A full-panel mode that restores the available width.
- Real viewport resizing, so the site's responsive CSS rules run.
- A current-width indicator that marks presets constrained by a narrow panel.
- Keyboard navigation and a menu that stays within the website viewport.

## Requirements

BB desktop 0.48.1 or newer, with Plugin SDK 0.6.104 or newer. Verified with BB 0.48.1. No account, API key or external service is required. Menu labels are currently in Russian.

## Limits

This is a layout preview. It does not emulate touch, device pixel ratio or a mobile User-Agent, and does not add DevTools. A preset cannot exceed the browser panel's available width. The chat's headless browser preview and web clients without native Browser tabs are unsupported.

Opening the menu does not move or resize the page, hide it, or capture a screenshot. BB's experimental toolbar API and browser layout structure may change in future versions.
