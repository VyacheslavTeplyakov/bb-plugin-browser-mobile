# Browser Mobile

Русская инструкция. [English](README.md).

Переключатель ширины встроенного браузера BB для проверки адаптивной вёрстки.

## Установка

Нужен **настольный BB 0.48.1 или новее**. В терминале на компьютере, где запущен BB, выполните:

```sh
bb plugin install https://github.com/VyacheslavTeplyakov/bb-plugin-browser-mobile
```

Подтвердите источник. Затем откройте или переоткройте вкладку Browser:
рядом с адресной строкой появится переключатель ширины. Отдельный `npm install` не нужен — BB сам
соберёт плагин. При первой сборке он может скачать свой toolchain.

### Установка из ZIP

Скачайте `browser-mobile-0.3.1.zip` из [Releases](https://github.com/VyacheslavTeplyakov/bb-plugin-browser-mobile/releases/latest), распакуйте в постоянную папку и выполните из родительской папки:

```sh
bb plugin install ./bb-plugin-browser-mobile
```

Подтвердите локальный источник. Папку плагина после установки нужно сохранить.

## Использование

Нажмите переключатель рядом с адресной строкой и выберите ширину:

| Режим | CSS px |
| --- | ---: |
| Вся панель | Авто |
| Маленький телефон | 360 |
| Телефон | 390 |
| Большой телефон | 430 |
| Планшет | 768 |
| Ноутбук / планшет | 1024 |
| Десктоп | 1280 |

Фиксированная ширина центрирует страницу. При узкой панели ширина ограничена
доступным местом, а индикатор показывает реальную ширину со звёздочкой. Выбранные
1280 px в панели 600 px означают фактический viewport 600 px. Для проверки
брейкпоинта 1280 px нужно расширить панель хотя бы до 1280 px.

Высота остаётся равной высоте панели. Режим действует до закрытия или
размонтирования вкладки; переход по ссылкам и перезагрузка его сохраняют.

Меняется размер настоящей браузерной области, поэтому работают media queries
сайта. Это проверка адаптивной вёрстки: User-Agent, touch, DPR и профиль
устройства не меняются. DevTools плагин не добавляет.

Меню открывается поверх живого сайта, внутри его viewport, в том числе в
мобильном режиме. Оно использует цвета темы BB и отдельный временный Shadow
DOM, чтобы CSS сайта не менял оформление. При открытии меню контейнер сайта
не сдвигается, его размеры не меняются; снимки и скрытие страницы не используются.

Меню открывается мышью или клавиатурой, закрывается выбором, Escape или
кликом снаружи. Стрелки, Home, End и Enter работают и при фокусе на кнопке BB,
и внутри меню.

## Совместимость

- Проверено на BB 0.48.1 с Plugin SDK 0.6.104. Используются экспериментальный API и структура браузерной панели; после обновлений BB может понадобиться исправление совместимости.
- Работает в настольной вкладке Browser. Headless preview в чате и web-клиент без нативного браузера не поддерживаются.
- Надписи меню сейчас на русском языке.
- Аккаунты, API-ключи и внешние сервисы не нужны. Плагин не добавляет телеметрию.

Отключение: `bb plugin disable browser-mobile` или настройки плагинов BB.
